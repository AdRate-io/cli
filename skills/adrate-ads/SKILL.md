# AdRate Ads

Run `adrate --version` first.

If `adrate` is missing or reports a version older than `0.1.0-beta.11`, run `npm install -g @adrate/cli@next`, then check the version again. Once the version is sufficient, run `adrate skills read adrate-ads` and follow the returned instructions.
